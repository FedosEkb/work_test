# 📖 Программа для чтения вещественных чисел и нахождения их прозведения

Консольная утилита для считывания вещестаенных чисел и нахождения их прозведения. 

## 💻 Сборка и совместимость
* **ОС:** Тестировалось и собиралось под **Ubuntu**. 
* **Портативность:** Должно успешно собираться и под другими дистрибутивами Linux.

## 🛠 Установка зависимостей
Для установки библиотеки **CLI11** выполните команду:
```bash
make install-deps
```
## 🧪 Тестирование
В корневом каталоге проекта находится скрипт для **генерации файлов с числовой последовательностью**, с помощью которого можно проверить работоспособность программы.
